LP Tracker

Tracker JavaScript para Landing Pages. Coleta eventos de interacao e persiste direto em PostgreSQL via uma API Flask. Uma tag <script> e tudo que voce precisa.

Ver como instalar

Como funciona

Arquitetura simples e direta

Landing Page     =>    script.js    =>    Flask API    =>    PostgreSQL                                                                                        
browser                                                                                   servidor                    banco
1

script.js carrega na LP

O browser baixa o script e comeca a rastrear automaticamente page_view, scrolls e cliques.

2

Eventos sao enviados

Cada interacao gera um payload JSON que e enviado via POST para o endpoint /v1/events.

3

Flask persiste no banco

A API valida o payload, resolve site e sessao, e insere o evento no PostgreSQL.

Instalacao

Adicione uma unica tag na sua Landing Page

<script
    src="https://tracker.seudominio.com/v1/script.js"
    data-site="meu-site"
    data-debug="true">
</script>

Atributos de configuracao

Atributo Obrigatorio Padrao Descricao
data-site Sim unknown Identificador do site. Site e criado automaticamente no primeiro evento.
data-webhook Nao /v1/events URL do endpoint de eventos.
data-debug Nao false Habilita logs no console ("true").
data-session-timeout Nao 30 Timeout da sessao em minutos.

Eventos rastreados

Todos esses eventos sao coletados automaticamente

Evento Quando dispara Unico por sessao
page_view Script carrega na pagina Sim
page_loaded Pagina completamente carregada Sim
scroll_25 25% da pagina rolada Sim
scroll_50 50% da pagina rolada Sim
scroll_75 75% da pagina rolada Sim
scroll_100 100% da pagina rolada Sim
button_click Clique em elemento com data-track Nao
page_exit Visitante sai da pagina (visibilitychange) Nao

Eventos personalizados

Use LPTracker.track() para rastrear qualquer interacao

Formulario

Rastreia quando o visitante comeca a preencher e quando envia.

// Ao focar no primeiro input
LPTracker.track("form_start",
  { form: "lead" });

// Ao enviar
LPTracker.track("form_submit",
  { form: "lead" });

VSL / Video

Rastreia reproducao, progresso e conclusao.

LPTracker.track("video_started",
  { video: "vsl", duration: 120 },
  { unique: true });

LPTracker.track("video_progress",
  { video: "vsl", percentage: 50 });

LPTracker.track("video_complete",
  { video: "vsl" });

WhatsApp

Rastreia cliques no botao do WhatsApp.

LPTracker.track("whatsapp_click",
  { position: "hero",
    phone: "5511999999999" });

Link externo

Rastreia cliques em links que saem do site.

LPTracker.track("link_click",
  { href: "https://...",
    text: "Visitar parceiro",
    position: "footer" });

CTA (data-track)

Elementos com data-track ja sao rastreados automaticamente.

<button
  data-track="cta"
  data-track-name="hero">
  Comecar agora
</button>

Evento unico

Use unique: true para eventos que devem ocorrer apenas uma vez por sessao.

LPTracker.track("video_started",
  { video: "vsl" },
  { unique: true });

API publica

Metodos disponiveis via window.LPTracker

LPTracker.track(nome, dados, opcoes) Enviar evento personalizado
LPTracker.getSessionId() Obter ID da sessao atual
LPTracker.getSession() Obter dados da sessao
LPTracker.getSiteId() Obter site_id configurado
LPTracker.getConfig() Obter configuracao completa
LPTracker.touch() Renovar atividade da sessao manualmente

Schema do banco

3 tabelas no PostgreSQL

Tabela Descricao Colunas principais
sites Cada Landing Page/cliente id, site_key, name, domain, active
sessions Sessao de navegacao de um visitante id, session_id, site_id, started_at, last_activity_at
events Cada evento rastreado id, event_id, site_id, session_id, event_name, timestamp, data
